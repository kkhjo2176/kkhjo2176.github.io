# GitHub Pages 포트폴리오

프레임워크나 빌드 과정 없이 실행하는 HTML/CSS/JavaScript 포트폴리오입니다.

## 적용 방법
1. 기존 kkhjo2176.github.io 저장소 내용을 먼저 백업합니다.
2. 이 압축파일의 index.html, style.css, script.js, .nojekyll을 저장소 최상위에 올립니다. README.md는 참고 문서입니다.
3. 기존 Vue/Vite 자동 배포 workflow가 있다면 비활성화하거나 이 정적 파일 구조에 맞게 변경합니다. 기존 workflow가 계속 빌드하면 새 파일 대신 이전 페이지가 배포될 수 있습니다.
4. 저장소 Settings → Pages에서 정적 파일이 있는 브랜치의 /(root)를 게시 대상으로 지정합니다. 현재 설정 화면에 따라 항목명은 다를 수 있습니다.
5. 배포가 끝나면 https://kkhjo2176.github.io/ 에서 확인합니다.

현재 GitHub 저장소에는 직접 변경하지 않았습니다.

## 파일 수정 위치
- index.html: 메인 소개, 경력, 기술, 학력·자격, GitHub 링크
- style.css: 색상, 글꼴, 반응형 레이아웃
- script.js: projects 배열의 프로젝트 설명, 담당 역할, 링크

표시 이름은 GitHub 계정 기반의 kkh로 구성했습니다. 실제 이름·이메일은 확정 후 추가하세요.
교육 기간은 정확한 날짜가 제공되지 않아 표시하지 않았습니다.
자격증 결과가 확정되면 정보처리기사 상태를 수정하세요.
실무 1·2는 개념도, 나머지 네 프로젝트는 제공된 실제 화면입니다. assets 폴더를 반드시 함께 업로드하세요.
Weather Mate는 화면 표시 이름이며 저장소 링크 weather-life는 그대로 유지합니다.
Apache 매뉴얼은 포함하지 않았습니다.
Weather Life 저장소는 확인 시 404를 반환했습니다. 공개 설정과 정확한 주소를 확인하세요.
팀 프로젝트 내용은 대화에서 제공된 본인 담당 기능을 기준으로 정리했으며 전체 소스 감사를 수행한 것은 아닙니다.

## PDF 다운로드 추가
최종 PDF를 assets/resume.pdf 등에 넣은 뒤 원하는 영역에 다음 링크를 추가합니다.
<a href="assets/resume.pdf" download>이력서 PDF 다운로드</a>
경력기술서와 자기소개서도 같은 방식으로 연결할 수 있습니다. 현재 존재하지 않는 문서에 연결되는 버튼은 넣지 않았습니다.

## 포크 저장소 README 작성
본인 포크의 README.md를 수정해 포트폴리오 설명으로 활용할 수 있습니다.
상단에 팀 프로젝트와 포크임을 밝히고 본인의 담당 역할, 구현 내용, 문제 해결, 실행 방법, 화면 캡처를 작성하세요.
팀원 기여, 원본 저장소 표시, 기존 라이선스와 저작권 고지는 유지하세요.
민감한 API 키나 DB 비밀번호가 저장소에 포함되지 않았는지 확인하세요.
